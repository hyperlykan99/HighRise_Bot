RADIO SOURCE INTELLIGENCE POLISH

Goal:
Make the radio system clearly explain the relationship between Auto DJ/vibe music and live user requests.

Do not rewrite the radio backend.
Do not change AzuraCast/SFTP logic.
Do not change request upload/download logic.
Do not touch emote system.
Do not break DJ_DUDU internal routing or BOT_MODE=dj.

Relevant files:
- modules/radio_commands.py
- modules/track_resolver.py
- modules/dj_announcer.py
- modules/playback_engine.py
- modules/request_queue.py
- modules/azuracast_controller.py
- modules/help_cmds.py

==================================================
1. SOURCE DEFINITIONS
==================================================

Use these meanings everywhere:

Auto DJ:
- Background vibe music from AzuraCast playlists.
- Plays when there are no active live requests.
- Shows current vibe name.

Live Request:
- A player-requested song from !play.
- Temporarily takes over the radio.
- Auto DJ/vibe resumes after requests finish.

User-facing labels:
- Auto DJ
- NOW PLAYING

Do not call vibe music “request”.
Do not call live requests “Auto DJ”.

==================================================
2. UPDATE !QUEUE
==================================================

Update !queue / !q so players understand what is happening.

If Auto DJ/vibe is playing and no live requests are queued:

🎧 Radio Status
Auto DJ: ON
📀 Vibe: <vibe_name>
📜 Requests: none
💿 !play to request a song

If Auto DJ/vibe is playing and requests are queued:

🎧 Radio Status
Auto DJ: ON • Vibe: <vibe_name>
📜 Requests: <n> pending
Next: @user — <title>
💿 !play to request a song

If a live request is currently playing:

🎧 Radio Status
NOW PLAYING: Live Request
📜 Requests: <n> pending
Next: @user — <title>
Auto DJ resumes after queue.
💿 !play to request a song

Keep output compact and under 249 chars.
Use pagination/chunking if needed.
Do not cut off.

4. UPDATE !RADIOHELP / !DJHELP
==================================================

Add a short explanation:

🎧 How Radio Works
Auto DJ plays vibe music when no requests are active.
Use !play <song> to request a song.
Requests play first, then Auto DJ resumes.

Show public commands:

💿 !play <song/URL> — Request a song
📜 !queue — See request queue
🎧 !np — Current song
📀 !vibe status — Current vibe
⭐ !fav — Save current song
📂 !playlist — VIP playlists

Keep !play as the advertised command.
Do not advertise !request as the main command.
