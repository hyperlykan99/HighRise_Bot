original local media → copy to Requests folder → queue normally → play when turn comes → cleanup copied request file only.

==================================================

- keep existing YouTube request pipeline.

1. find original media by:

2. copy original file into Requests folder
3. create a normal queue/request job for the copied file
4. mark source_type/local_copy if needed
5. play it when its turn comes
6. cleanup copied file after playback

Success:
