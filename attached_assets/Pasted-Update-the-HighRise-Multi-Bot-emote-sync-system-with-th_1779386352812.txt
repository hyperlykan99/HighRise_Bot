PART 2 — ADD !sync all FEATURE
==================================================

Add a new sync command:

!sync all

Behavior:
Sync all current non-bot players in the room to the command sender.

Example:
If owner/admin types:

!sync all

Then every non-bot player in the room should become a sync follower of the command sender.

Also support:

!sync all @player

Behavior:
Sync all current non-bot players in the room to @player.

Example:
If owner/admin types:

!sync all @AshQuinn_

Then every non-bot player in the room should become a sync follower of AshQuinn_.

Permissions:
Only owner/admin can use !sync all.

Allowed:
- owner: !sync all
- owner: !sync all @player
- admin/staff: !sync all
- admin/staff: !sync all @player

Blocked:
- normal players
- VIP users
- bots

Blocked message:

❌ Only owner/admin can sync everyone.

Do not allow normal users or VIP users to control everyone’s sync.
