D) SYNC EMOTES

Add:
!sync @user <emote>

Everyone can use it.

Example:
!sync @Claire sweetjammer

Behavior:
- Resolve target in room
- Validate emote exists and is player-usable
- Sender and target both start same looping emote
- Uses registry timing
- Both loops stay synced as close as possible
- Either user can stop using:
  !syncstop
  Stop

Also support shortcut:
<emote> @user

Example:
sweetjammer @Claire

E) SYNC STOP

Add:
!syncstop

Behavior:
- Stops sender’s active sync
- Stops linked target’s active sync too
- Clean task cancellation
- Clear sync state for both users

F) STAFF ROOM-WIDE EMOTE

Add:
!emote all <emote>

Staff only.

Behavior:
- All current players in room perform/loop the emote
- Uses registry timing
- Ignore bots
- Non-staff blocked
- Add:
  !emote all stop

H) DANCEFLOOR SYSTEM

Add commands:
!dancefloor setpoint 1
!dancefloor setpoint 2
!dancefloor save
!dancefloor emotes <emote1>, <emote2>, <emote3>
!dancefloor emotes random 10
!dancefloor start
!dancefloor stop
!dancefloor status
!dancefloor clear

Permissions:
Staff only for setup/start/stop.

Behavior:
- Two points define rectangular dancefloor box
- Save box coordinates in DB
- Detect players inside box
- Players inside dancefloor auto-loop selected emotes
- Players leaving box stop dancefloor loop
- Uses registry timing
- Excludes bots
- Random option:
  !dancefloor emotes random 10
  randomly selects 10 valid player emotes from registry
- Random list persists after restart
