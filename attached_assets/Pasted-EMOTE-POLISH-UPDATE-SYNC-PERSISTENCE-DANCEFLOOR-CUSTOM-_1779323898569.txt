B) DANCEFLOOR CUSTOM SEQUENCES

Make dancefloor work like custom emotes.

Commands:

!dancefloor emotes justvibing sit aerobics
- uses registry timing

!dancefloor timed justvibing 6 hipshake 10 laidback 3
- uses custom timing only for dancefloor
- does NOT update registry timing

!dancefloor random <number>
Examples:
!dancefloor random 20
!dancefloor random 75
!dancefloor random 9999

Rules:
- REMOVE old hard cap min(50, int(N)).
- No hard cap.
- If requested number > available player emotes, use all available valid player emotes.
- Exclude bot-only emotes.
- Exclude social/combat/reaction emotes.
- Shuffle order.
- Save as dancefloor sequence.

Also:
!dancefloor random
= use all valid player emotes.
