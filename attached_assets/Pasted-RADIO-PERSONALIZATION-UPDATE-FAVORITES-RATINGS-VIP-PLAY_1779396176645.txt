PART 2 — FAVORITES
==================================================

Add or clean these commands:

!favorite
!fav

Behavior:
Save the current playing song to the user's favorites.

Also support:

!favorites
!favs

Behavior:
Show the user's saved favorites.

Also support:

!unfav <#>

Behavior:
Remove a favorite by number from the user's favorites list.

Optional if already supported safely:

!playfav <#>

Behavior:
Request/play a saved favorite by number.

Important:
Use safe pagination for favorites list.
Never send a message over 249 characters.

Favorites must support both:
1. YouTube/requested songs
2. Local AzuraCast/media library songs

Do not require youtube_url to save a favorite.

If the current song is local radio/media and has no YouTube URL:
Save stable metadata instead:
- title
- artist if available
- AzuraCast song unique_id if available
- AzuraCast media/file ID if available
- source_type = local or azuracast
- youtube_url = NULL/empty

Display local favorites as:
🎵 Title — Artist
Source: Local Radio

Do not expose private server paths.

Duplicate rule:
Do not allow the same user to favorite the same song twice.
Match by:
- YouTube URL if available
- else AzuraCast song ID if available
- else normalized title + artist

Responses:
✅ Added to favorites: <title>
⭐ Already in your favorites.
❌ Nothing is currently playing.
✅ Removed favorite #<n>: <title>
❌ Favorite not found.

PART 4 — VIP PERSONAL PLAYLISTS
==================================================

Add VIP-only personal playlists.

Permissions:
Normal users:
- cannot create/manage playlists
- can still use normal radio commands

VIP:
- can create/manage/play their own playlists

Admin/owner:
- can use playlists too

Use existing VIP detection logic.
Do not create a duplicate VIP system.
Reuse modules.vip, database owns_item("vip"), or existing project helper.

Commands:

!playlist

Behavior:
Show the user's playlists.
This is the ONLY advertised command for showing playlist list.

Do NOT advertise:
!playlist list
!pl list

Main playlist commands:

!playlist create <name>
Create a playlist.

!playlist songs <name>
Show songs inside a playlist.

!playlist add <name> <song or YouTube URL>
Add a song or YouTube URL to a playlist.

!playlist addcurrent <name>
Add the current playing song to a playlist.

!playlist rename <old> <new>
Rename a playlist.

!playlist remove <name> <#>
Remove a song from a playlist by number.

!playlist delete <name>
Delete a playlist.

!playlist play <name>
Queue songs from a playlist.

Optional short alias:
!pl may work as an alias for !playlist if safe.
But help should advertise !playlist as the main command.

Limits:
- Max playlists per VIP: 5
- Max songs per playlist: 25
- Max playlist name length: 24 characters
- No duplicate songs inside the same playlist
- Playlist names should be sanitized: letters, numbers, spaces, dash, underscore only
- Do not allow empty playlist names
- Do not allow abusive giant input

Normal blocked message:
🔒 VIP only. Upgrade to VIP to create radio playlists.

Responses:
✅ Created playlist: <name>
📂 Your playlists:
1. Chill Mix — 12 songs
2. Party — 8 songs

✅ Added to <playlist>: <title>
⭐ Already in that playlist.
✅ Removed #<n> from <playlist>: <title>
✅ Renamed playlist <old> → <new>
✅ Deleted playlist: <name>
❌ Playlist not found.
❌ Playlist limit reached. Max 5 playlists.
❌ Song limit reached. Max 25 songs per playlist.

PART 5 — PLAYLIST SONG SUPPORT FOR YOUTUBE AND LOCAL MEDIA
==================================================

Playlist songs must support both:
1. YouTube/requested songs
2. Local AzuraCast/media library songs

For YouTube songs, store:
- source_type = youtube
- title
- artist if available
- youtube_url
- video_id if available

For local/AzuraCast songs, store:
- source_type = local or azuracast
- title
- artist
- azura_song_id if available
- azura_file_id if available
- media_id if available
- youtube_url = NULL/empty

Do not require youtube_url.

Do not expose local file paths or private media paths.

When showing playlist songs:
YouTube:
1. 🎵 Title — Artist
   Source: YouTube

Local:
1. 🎵 Title — Artist
   Source: Local Radio

When using:
!playlist addcurrent <name>

If current song is local media, it should still save.

When using:
!playlist play <name>

Behavior:
- For YouTube songs: use existing request/queue pipeline.
- For local/AzuraCast songs:
  - If existing project supports requesting/queueing local AzuraCast media by song/file ID, use that.
  - If replaying local media is not supported yet, do not fail the whole playlist.
  - Show:
    ⚠️ Skipped local song: <title> — local replay not supported yet.
  - Continue queueing supported YouTube songs.

Do not instantly upload/play 25 songs at once in an unsafe way.
Queue safely using existing queue/request limits.

If queue is full:
⚠️ Queue is full. Added <n>/<total> songs.
