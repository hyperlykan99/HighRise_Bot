ADD CUSTOM EMOTE SEQUENCE SYSTEM.

Do not touch bot startup, tokens, music, casino, sync, or dancefloor unless needed for clean integration.

Goal:
Create public instant custom emote loops and saved personal custom emote packs.

1. Public instant commands

!customemote <emote1> <emote2> <emote3>
Example:
!customemote justvibing sit aerobics

Behavior:
- Starts looping those emotes in order on the command user
- Uses registry timing for each emote
- Repeats forever until stopped

!customtimed <emote1> <seconds1> <emote2> <seconds2>
Example:
!customtimed justvibing 6 hipshake 10 laidback 3

Behavior:
- Starts looping those emotes in order
- Uses provided seconds instead of registry timing
- Repeats forever until stopped

!stopcustom
Stops the user’s active custom emote loop.

2. Saved personal packs

!savecustom <packname> <emote1> <emote2> <emote3>
Example:
!savecustom chillpack justvibing sit aerobics

!savecustomtimed <packname> <emote1> <seconds1> <emote2> <seconds2>
Example:
!savecustomtimed vibeloop justvibing 6 hipshake 10 laidback 3

Rules:
- Packs are saved per user_id
- Different players can use the same pack name
- Validate emotes before saving
- Timed packs must validate every time value is positive

3. Play/manage saved packs

!playcustom <packname>
Loops the user’s saved pack.

!custompacks
Shows user’s saved packs alphabetically.

!custominfo <packname>
Shows pack name, mode, emotes, and timings.

!renamecustom <oldname> <newname>
Renames user’s saved pack.

!deletecustom <packname>
Deletes user’s saved pack.

4. Engine rules

Use one shared custom sequence runner:
- cancel existing custom loop for user before starting new one
- cancel normal player emote loop before starting custom
- if user types Stop, also stop custom loop
- if user uses !syncstop, do not break custom unless needed
- if user starts !sync @leader, cancel custom loop so sync owns them
- if user enters dancefloor, dancefloor may override custom loop
- use registry get_emote_time for simple mode
- use custom seconds for timed mode

5. Persistence

Create DB table if needed:
