EMOTE STRUCTURE
━━━━━━━━━━━━━━━━━━

Each emote contains:

display name
SDK emote ID
duration

Example:

{
  "value": "emote-wave",
  "text": "The Wave",
  "time": 2.690873
}

Use:
value
as exact SDK emote ID.

Use:
text
for display.

Use:
time
for loop timing.
