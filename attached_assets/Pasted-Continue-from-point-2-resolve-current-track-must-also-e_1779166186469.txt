2. Request Match Comes First
━━━━━━━━━━

Request detection order:

1. media_id / song_id
2. AzuraCast unique_id
3. path starts with Requests/
4. filename match
5. youtube_id stored in DB
6. normalized title + artist
7. fuzzy title match last

If matched:
- source = "request"
- set current_request
- set requester
- set started_at
- remove from queue/up next
- DO NOT show AutoDJ

If not matched:
- source = "autodj"

━━━━━━━━━━
3. Fix AutoDJ Vibe
━━━━━━━━━━

If source == autodj:
show actual active vibe.

Never hardcode Chill.

Vibe resolution order:
1. active vibe set by !vibe
2. AzuraCast playlist name
3. active enabled playlist
4. fallback "AutoDJ"

Examples:
🌙 AutoDJ • Bgcnights
🌙 AutoDJ • Chill
🌙 AutoDJ • Phonk
