2. TRUE !SYNC SYSTEM
==================================================

Current behavior is wrong.

NEW BEHAVIOR:

!sync @targetuser

Means:
The command user COPY/SYNCS the TARGET USER'S current emotes/movements continuously.

Example:
AshQuinn_ starts dancing.
I type:
!sync @AshQuinn_

My character now mirrors/syncs whatever AshQuinn_ is doing.

If target changes emote:
sync user updates too.

If target stops:
sync user stops too.

If target walks:
sync user follows movement animation/emote state only (NOT physical teleport follow).

==================================================
3. !SYNC RULES
==================================================

Everyone can use !sync.

Requirements:
- target must exist in room
- cannot sync to self
- multiple users may sync same target
- syncing survives emote loops
- syncing works with dancefloor emotes
- syncing works with bot emotes
- syncing works with manual player emotes

Commands:

!sync @user
Start syncing to target

!syncstop
Stop syncing

Stop
Also breaks sync

If sync active:
new !sync replaces previous target.
