==================================================
4. LIGHTWEIGHT REWARDS
==================================================

Add small rewards for radio engagement.

Reward actions:
- successful song request
- first like/dislike per song
- saving a favorite
- creating a playlist
- adding a song to a playlist
- playing a playlist song

Rewards should be small:
- small XP if profile/XP system exists
- small ChillCoins if economy helpers exist
- radio_points always safe to add

Recommended:
Successful request: +5 radio points
Like/dislike first time: +1 radio point
Favorite: +2 radio points
Playlist create: +3 radio points
Playlist song add: +1 radio point
Playlist play: +2 radio points

If XP/coins are added:
keep very small and respect daily caps.

Do not give large economy rewards.

==================================================
5. ANTI-SPAM / DAILY CAPS
==================================================

Prevent farming.

Rules:
- Reward like/dislike only once per user per song.
- Changing like to dislike should not give another reward.
- Favoriting the same song twice gives no reward.
- Creating/deleting/recreating same playlist name should not farm rewards.
- Playlist add duplicate song gives no reward.
- Failed request gives no reward.
- Blocked/cooldown request gives no reward.

Add daily cap:
- max radio_points reward per user per day, default 50
- optional max coins/XP per day if used

Suggested table:
radio_reward_log:
- id
- user_id
- username
- action
- song_key nullable
- target_key nullable
- points
- rewarded_at
- reward_day

Use this to prevent duplicate rewards.

6. INTEGRATE WITH EXISTING ACTIONS
==================================================

Hook stats/rewards into existing commands:

- increment request count
- add radio points
- update song request count

- increment likes_count only if first rating for this song
- add radio points once
- update song like count

!dislike:
- increment dislikes_count only if first rating for this song
- add radio points once
- update song dislike count

!fav / !favorite:
- increment favorites_count only when newly favorited
- add radio points once
- update song favorite count

!playlist create:
- increment playlists_created only on successful new playlist
- add points once

!playlist add / addcurrent:
- increment playlist_songs_added only on successful non-duplicate add
- add points once

!playlist play:
- increment playlist_plays on successful queue/play
- add points with cap

Do not reward actions that only show lists:
- !favorites
- !playlist
- !queue
- !np
- !history
