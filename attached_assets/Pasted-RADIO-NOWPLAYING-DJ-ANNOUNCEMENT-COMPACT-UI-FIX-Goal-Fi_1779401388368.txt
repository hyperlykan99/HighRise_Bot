==================================================
1. FIX HEADER CUTOFF
==================================================

Issue:
The current header “DJ DUDU RADIO” is too long and gets cut/wrapped in HighRise chat.

Fix:
Use a shorter compact header in user-facing now-playing cards and DJ announcements:

🎧 DJ RADIO • Now Playing

For request live:

🎧 DJ RADIO • Request Live

Do not use the long “DJ DUDU RADIO” header in the compact card if it causes cutoff/wrapping.

Internal bot/account name can stay DJ_DUDU for routing.
Only change display text.

==================================================
2. REMOVE GAPS / BLANK LINES
==================================================

Issue:
The card is too big because it has too many blank lines and vertical gaps.

Fix:
Remove unnecessary blank lines.

Use compact layout with no spacer gaps:

==================================================

Use compact one-line song info:

🎵 <title> — <artist>

Examples:

🎵 MOLIY — Silent Addy

<title>

🎤 Artist:
<artist>

That takes too much vertical space.
