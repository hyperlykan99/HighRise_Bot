PART 1 — Replace the current !now player format

Problem:
The current bordered ChillTopia Player box is too wide. Highrise adds the bot name before the message, so the first line wraps and looks jumbled.

Replace the !now / !nowplaying / !np output with short vertical formats.

For AutoDJ / Chill / Party:

▶ NOW PLAYING
🎵 {track}
🌙 AutoDJ • Chill
⏱ {elapsed} / {duration}
▰▰▰▰▱▱▱▱▱▱
📻 ChillTopia Radio

For Party AutoDJ:

▶ NOW PLAYING
🎵 {track}
🔥 AutoDJ • Party
⏱ {elapsed} / {duration}
▰▰▰▰▱▱▱▱▱▱
📻 ChillTopia Radio

For request:

▶ REQUEST LIVE
🎵 {track}
🙋 @{username}
⏱ {elapsed} / {duration}
▰▰▰▰▱▱▱▱▱▱
📻 ChillTopia Radio

Formatting rules:
- No large borders.
- No side border characters.
- Keep each line short.
- Trim track to 42 characters max.
- If elapsed/duration is unavailable, show:
  ⏱ Live stream
- Progress bar must be 10 blocks.
- Use ▰ for filled and ▱ for empty.
- !now, !nowplaying, and !np must all use this exact same handler.
- If current song matches a request job, show REQUEST LIVE.
- Otherwise show AutoDJ with current vibe from config_store.
